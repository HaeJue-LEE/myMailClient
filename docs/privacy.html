개인정보처리방침

myMailClient · 시행일 2026년 11월 12일

myMailClient(이하 “앱”)는 사용자의 PC에서 실행되는 Windows 데스크톱 메일 프로그램입니다. 이 방침은 앱이 어떤 정보를 어디에 저장하고 어떻게 사용하는지 설명합니다.

요약
  • 앱에는 개발자가 운영하는 서버가 없습니다. 모든 처리는 사용자의 PC에서 이루어집니다.
  • 메일, 계정 정보, 연락처를 개발자나 제3자에게 보내거나 판매하지 않습니다.
  • 광고, 사용 통계, 분석 도구를 사용하지 않습니다.

1. 앱이 접근하는 정보

Google 계정 (Google 로그인을 사용하는 경우)

사용자가 Google 로그인 화면에서 허용한 범위 안에서만 다음 정보에 접근합니다.

  • Gmail (https://www.googleapis.com/auth/gmail.modify): 메일 목록과 내용을 보여 주고, 읽음·별표·보관·휴지통 같은 상태를 바꾸고, 사용자가 쓴 메일과 임시저장 메일을 보내거나 저장합니다. 받은 메일과 보낸 메일은 영구 삭제하지 않습니다(휴지통으로만 옮김). 사용자가 지운 임시저장 메일은 Gmail에서 바로 삭제됩니다.
  • Google 주소록 (https://www.googleapis.com/auth/contacts): 저장된 연락처를 받는사람 자동완성에 쓰고, 사용자가 요청하면 연락처를 추가·수정·삭제합니다.
  • 기타 연락처 (https://www.googleapis.com/auth/contacts.other.readonly): 메일을 주고받은 사람의 주소를 자동완성에 씁니다. 읽기만 합니다.
  • Google 계정 이메일 주소: 앱에 추가된 계정을 구분해 표시하는 데 씁니다.

IMAP·POP3 메일 계정

사용자가 입력한 메일 주소, 서버 주소, 사용자 이름, 비밀번호를 사용해 해당 메일 서버에 직접 접속합니다. 메일은 사용자의 메일 서버와 사용자의 PC 사이에서만 오갑니다.

Zoho 메일 계정 (Zoho 로그인을 사용하는 경우)

사용자가 직접 만든 Zoho API 클라이언트로 Zoho 승인 화면에서 허용한 범위(메일 계정 정보, 메일, 폴더) 안에서만 Zoho Mail API에 접속해 메일 목록과 내용을 읽고, 읽음·플래그를 바꾸고, 메일과 임시보관 메일을 저장·발송합니다. 메일은 Zoho와 사용자의 PC 사이에서만 오갑니다.

2. 저장 위치와 보호

  • 모든 설정과 데이터는 사용자의 PC(%APPDATA%\Mail Client)에만 저장됩니다.
  • Google·Zoho 로그인 정보(갱신 토큰), 메일 계정 비밀번호, 사용자가 입력한 Google·Zoho 클라이언트 보안 비밀은 Windows가 제공하는 암호화(DPAPI)로 암호화되어, 같은 Windows 사용자 계정에서만 읽을 수 있습니다.
  • POP3 계정의 읽음 표시, 임시저장 메일, 보낸 메일 사본, 계정 사진도 같은 위치에만 저장됩니다.

3. 제3자 제공

앱은 사용자의 정보를 개발자나 제3자에게 전송, 공유, 판매하지 않습니다. 앱이 접속하는 곳은 Google API(Gmail, People), Zoho(로그인, Zoho Mail API)와 사용자가 등록한 메일 서버뿐이며, 이는 사용자가 요청한 기능을 수행하기 위한 것입니다.

4. Google 사용자 데이터 사용에 관한 고지

myMailClient가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 일은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. Google 사용자 데이터는 앱의 메일·연락처 기능을 제공하는 데만 쓰이며, 광고, 신용 평가, 인공지능 모델 학습에 쓰이지 않고, 사람이 열람하지 않습니다.

myMailClient's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. 보관 기간과 삭제

  • 앱의 메일 계정 화면에서 계정을 삭제하면 그 계정의 설정, 암호화된 비밀번호와 로그인 정보, PC에 저장된 관련 데이터가 함께 삭제됩니다. Google 계정은 이때 로그아웃되며 앱의 접근 권한도 철회됩니다.
  • Google 계정의 앱 접근 권한은 Google 계정 → 보안 → 타사 앱 및 서비스에서 언제든지 철회할 수 있습니다.
  • 앱을 지우려면 앱 폴더와 %APPDATA%\Mail Client 폴더를 삭제하면 됩니다. 메일 자체는 Google이나 각 메일 서버에 그대로 남습니다.

6. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 의도적으로 수집하지 않습니다.
