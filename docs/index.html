myMailClient

Gmail과 네이버·하이웍스 같은 IMAP·POP3 메일 계정을 한곳에서 쓰는 Windows 데스크톱 메일 프로그램입니다. 설치된 창 이름은 Mail Client로 표시됩니다.

주요 기능

  • Gmail(Google 로그인) 계정과 IMAP·POP3 계정을 여러 개 추가하고 바꿔 가며 사용
  • 메일 읽기, 쓰기, 답장, 전달, 임시저장, 첨부파일
  • 메일과 메일 쓰기 창을 별도 창(팝업)으로 열기
  • Google 주소록의 연락처를 받는사람 자동완성에 사용하고, 새 연락처 저장

개인정보

myMailClient는 별도의 서버가 없습니다. 메일 계정 설정과 로그인 정보는 사용자의 PC에만 암호화해 저장되며, Google 계정의 데이터는 사용자가 앱 안에서 요청한 기능에만 쓰이고 개발자나 제3자에게 전송되지 않습니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.

설치

최신 버전 내려받기 (Windows 10 이상, 64비트)

내려받은 MailClient-<버전>.exe를 빈 폴더에 두고 실행하면, 처음 한 번 같은 폴더의 Mail Client 폴더에 앱을 준비한 뒤 실행합니다. 이후에는 바로 실행됩니다. 코드 서명이 없어 처음 실행할 때 Windows SmartScreen 경고가 나오면 “추가 정보” → “실행”을 눌러 주세요. 릴리스 페이지에 적힌 SHA-256 값으로 파일이 바뀌지 않았는지 확인할 수 있습니다.
